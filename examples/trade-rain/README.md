Trade Rain demo
----------------

This is a minimal standalone prototype that reproduces a "Trade Rain" overlay using a canvas-based particle renderer. It simulates trades and draws falling/fading circles colored by side and sized by volume.

How to run

- Open `examples/trade-rain/index.html` in a browser (file://) or serve the folder with a static server.

Optional: run a local static server:

```bash
npx serve examples/trade-rain
```
